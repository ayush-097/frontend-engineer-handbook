# Homework: Lighthouse Audit

Score 90+ on Lighthouse Performance.

## Steps

1. **Run audit:**
   ```bash
   npm run build
   npm run preview
   # Open DevTools → Lighthouse → Run audit
   ```

2. **Fix issues:**
   Lighthouse shows specific problems. Fix each:
   - Optimize images
   - Eliminate render-blocking resources
   - Reduce unused JavaScript
   - Minimize main-thread work
   - etc.

3. **Re-audit:**
   Repeat until score > 90

4. **Document:**
   `LIGHTHOUSE.md` with:
   - Before/after screenshots
   - List of fixes applied
   - Final scores (Performance, Accessibility, Best Practices, SEO)

**Time:** 1-2 hours  
**Grading:** 5 pts
