# Homework: E2E Critical Paths

Test 3 critical revenue-generating paths with Playwright.

## Paths to Test

### 1. User Registration + First Purchase
Complete flow from landing page to confirmed order.

### 2. Return User Checkout
Logged-in user with saved payment buys product.

### 3. Password Reset Flow
User requests password reset, receives email, sets new password, logs in.

## Requirements
- Use Page Object pattern
- Handle async properly (no arbitrary waits)
- Assert on success outcomes
- Test both happy path and 1 error case per flow

## Deliverable
- 3 E2E tests
- Page Object classes
- Screenshot of passing tests

**Time:** 3-4 hours  
**Grading:** 5 pts
